# Product Requirements Document: Automated Night Sky Image Classification

## 1. Introduction/Overview
This document outlines the requirements for a machine learning project designed to automate the classification of night sky images. The system will process JPG images generated by a UFOCapture setup, which stacks video frames of detected objects. The goal is to eliminate the manual effort required to sort these images by identifying their content. The model will classify each image into one of three categories: "fireballs," "regular meteors," or "no meteors."

## 2. Goals
*   **Primary Goal:** Automate the sorting of JPG images from the UFOCapture system to improve efficiency.
*   **MVP Goal:** Create a functional command-line script that processes a directory of images and moves them into categorized subfolders based on the model's prediction.
*   **Technical Goal:** Utilize the PyTorch framework to build and train a neural network for the classification task.

## 3. User Stories
*   As an operator of the sky-watching camera, I want to run a single script on a folder full of captured images so that they are automatically sorted into `fireballs`, `meteors`, and `no_meteors` folders, saving me hours of manual review.

## 4. Functional Requirements
1.  The system must be a Python script executable from the command line.
2.  The script must accept one argument: the absolute path to a directory containing the `.jpg` images to be processed.
3.  Upon execution, the script shall create three subdirectories within the target directory if they do not already exist: `fireballs`, `meteors`, and `no_meteors`.
4.  The script must iterate through every `.jpg` image in the specified directory.
5.  For each image, the script will use a pre-trained PyTorch model to predict its category.
6.  The script must move the processed image file into the corresponding category subfolder (`fireballs`, `meteors`, or `no_meteors`).
7.  The script should process images in the root of the target directory and ignore images already in the category subfolders.

## 5. Non-Goals (Out of Scope for MVP)
*   Real-time classification directly from the UFOCapture software or camera feed.
*   The ability to process the source video files (`.avi` or other formats). The system will only work with the stacked `.jpg` images.
*   A graphical user interface (GUI) for interacting with the model.
*   A feature for manually reviewing, correcting, or re-labeling the model's classifications.
*   Generation of a separate report or log file (files are simply moved).

## 6. Technical Considerations
*   **Framework:** The machine learning model will be developed using PyTorch.
*   **Model:** A Convolutional Neural Network (CNN) will be designed and trained for this image classification task.
*   **Training Data:** The initial model will be trained on the provided 300 sample images, which are assumed to be evenly distributed across the three categories.
*   **Environment:** The script will be written in Python and will have dependencies such as PyTorch, torchvision, and Pillow. A `requirements.txt` file should be provided.

## 7. Success Metrics
*   **MVP Success:** The script is successfully delivered and can process a folder of images, moving them into the correct subfolders as described in the functional requirements.
*   **Classification Accuracy:** For the MVP, a "best effort" accuracy is acceptable. The primary goal is a functional end-to-end pipeline. Future iterations will focus on improving model performance.

## 8. Open Questions
*   What are the exact dimensions (height x width) of the source JPG images? Answer is: 1920x1080
*   Are the images color (RGB) or grayscale? Answer is: RGB
